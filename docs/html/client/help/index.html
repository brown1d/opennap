Help desk

Quick answers for the Windows client.

Connecting

Use the server address supplied by your OpenNap operator. The connection indicator in the main window tells you when login finishes.

Creating or using an account

Choose an available nickname and finish every page of the setup wizard. On the next launch, use the same nickname and password.

Search and transfers

Search by artist or track title. If a transfer stays queued, try another result. Two firewalled clients may be unable to transfer directly.

Choosing a music folder

Choose a specific folder on your hard drive for your MP3s. If Windows displays a No Disk dialog, close it and check for empty removable drives before scanning again.
